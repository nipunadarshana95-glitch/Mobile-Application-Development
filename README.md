# 📱 TechCare Services

**TechCare Services** is a comprehensive mobile application designed to connect users with service technicians for electronic and appliance repairs. The application bridges the gap between customers looking for reliable repairs and technicians offering specialized services.

## 🛠️ Project Features

* **Service Categorization:** Browse through different repair categories, including mobile phones, laptops, refrigerators, televisions, and air conditioners.
* **User and Technician Profiles:** Separate authentication flows for standard customers and service technicians.
* **Service Requests:** Submit repair requests with descriptions and image attachments for faster diagnostics and troubleshooting.
* **Interactive Dashboard:** A highly intuitive, responsive, and user-friendly interface designed with custom panels and drawer navigation.

## 🚀 Getting Started

Follow these steps to set up and run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nipunadarshana95-glitch/Mobile-Application-Development.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd "77_46/TechCareServices - Copy"
   ```

3. **Install dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run the application:**
   ```bash
   flutter run
   ```
